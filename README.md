# Moby Fitness — Landing Page

Landing page em Next.js, TypeScript, Tailwind CSS e Framer Motion.

## Rodar localmente

```bash
npm install
npm run dev
```

## Antes da publicação oficial

- Confirmar endereço, horário e condições da aula experimental.
- Confirmar o link oficial do Instagram.
- Substituir imagens editoriais por fotos originais em alta resolução da academia.
- Confirmar autorização para manter nomes e comentários públicos na página.
